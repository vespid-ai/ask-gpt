# Security Policy

## Supported Versions

This project is early-stage open source. Security fixes are applied to the default branch until formal releases are introduced.

## Reporting a Vulnerability

Please report sensitive security issues privately to the maintainers instead of opening a public issue. Include:

- A clear description of the issue.
- Steps to reproduce.
- The affected browser and extension version or commit.
- Any relevant logs or screenshots with secrets removed.

We will acknowledge valid reports as quickly as possible and coordinate a fix before public disclosure.
